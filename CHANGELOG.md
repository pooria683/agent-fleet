# Changelog

## 0.1.0 — unreleased

Initial local-first MVP.

- TypeScript CLI and Ink workbench with bounded parallel execution.
- Claude Code, Codex and generic command adapters; Cursor/generic configuration example.
- Independent Git worktrees/branches, raw stdout/stderr/tool logs and atomic run manifests.
- Private-index snapshots including untracked and binary changes.
- Configurable setup/lint/test commands, transparent heuristic scores and Markdown comparison reports.
- Actual reported-cost/token accounting; unknown cost is never treated as free.
- Complete diff/log inspection, explicit conflict-checked merge and retained evidence.
- Process-group timeout/cancellation, dirty-source protection and interrupted-run recovery.
- Offline deterministic demo, real-Git integration tests, TUI tests and Ubuntu/macOS CI.
